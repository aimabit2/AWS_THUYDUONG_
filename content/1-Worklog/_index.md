This worklog records the complete 8-week internship journey. Each week is documented based on practical activities, including research, training sessions, team collaboration, and assigned project tasks.

Throughout the program, I progressively built knowledge around core AWS services, Data Lake architecture, Data Engineering workflows, and modern software development practices. Alongside theoretical study, I applied these skills directly to the Financial Data Lake project—from system analysis and ETL design to data ingestion pipeline implementation, secure networking architecture, observability, and frontend distribution.

The worklog is organized weekly to reflect the transition from foundational learning to applied execution. Each week presents key topics studied, tasks completed, lessons learned, and measurable results, demonstrating the growth of technical expertise and hands-on capability in Cloud Computing and Data Engineering.

As the program advanced, the focus evolved from understanding AWS architecture fundamentals and AI-driven SDLC, through building data platform and networking foundations, to automating infrastructure, securing cloud operations, and delivering a serverless analytics pipeline with an optimized frontend.

This document is intended to show not only what I learned, but how I used that knowledge in real project work, how I coordinated with the team, and how each weekly milestone contributed to the overall Financial Data Lake implementation.
